# 资产目录交付适配 203

本规则只简化交付排版，不缩减重要资产范围，不删身份、别名、所属、造型、视觉事实、关键文字、证据或出场信息。

直接返回紧凑 JSON：不要缩进和空白行，不重复字段，不在目录外写分析。每项 description 集中写全能让参考图画对的视觉事实，不复述整个剧情、对白或人物动机；storyFunction 和 importanceReason 各说明不同信息，不互相抄同一句空泛理由。证据选最能定位身份与必要性的一到数条原文短引，避免同一信息换句话重复；不得因简洁漏掉重要配角或关键物品。

没有内容的 variant、identity、aliases、storyFunction、importanceReason、evidence、appearsIn 可省略；已有内容正常保留。规范名 name、描述 description 和三个顶层数组保持原协议。不要为了省字段猜造型、归属或证据，也不减少资产数量凑短输出。单次读取完整本段，直接交付目录，不增加审查或第二次调用。
