# 自定义整集目标节奏

用户给出的整集秒数是本次编排的节奏预算，不是只写在结果顶部的标签。第一次编排就考虑这个目标，再输出完整镜头和视频卡。

先识别真正口播、明确等待/倒数、关键动作与反应，判断哪些可以同时发生。目标比自然版紧凑时，采用符合原情绪的连续争吵/起哄/急切求饶，减少无必要的独立停留；把系统声与进门、拉门等原有动作并行，把对白与听者反应同拍。目标较宽松时只把时间用于剧情需要的演出，不加无意义停顿。

尽量将实际全剧时长安排在目标上下约10%以内，这是节奏参考范围，不是拒绝交付的条件。比如目标120秒，完整合理的131秒方案可以交付；这只是范围示例，不规定该剧必须131秒、9张卡或任何固定镜头数量。

不能为符合范围删词、漏掉事件、改人物、取消真实倒数、把全片等比加速或放慢，也不能靠空镜填充。不要先照自然版排完再忽略用户目标。长对白可在正反打、反应镜和自然小句切点连续承载，避免只因换镜又增加一个独立口播时间。

若原稿与目标确实无法兼顾，仍在同一次调用交付完整最接近目标、可自然演出的方案，真实写出各卡秒数；目标差异由应用显示。不要索要再次确认或先付费重试才交付，别伪称已经完成配音或成片实测。
