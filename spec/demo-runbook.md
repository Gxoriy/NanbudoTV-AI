## 2. 现场四幕（每幕都有实测耗时，可按时间取舍）

### 第一幕：门控与登录（约 1 分钟）

1. 打开 `http://127.0.0.1:<port>` → 提示"请先激活卡密"
2. **先演示错误卡被拒**：随便填一张 → 页面显示中文提示「卡密无效，请核对后重试。」
   （这条是刻意修的：旧接口只回 `invalid_card`，用户看到的是英文码）
3. 输入真卡 `DW-PWMB-…` → 进入首页

> 讲点：设备码由浏览器 UA 派生，登录即绑定；`license.db` 的 `activations` 从 0 变 1。

### 第二幕：短剧主线（约 3~4 分钟，最有说服力）

1. 首页 → **短剧项目中心**（列表里能看到 `测试-202611161707`）
2. 新建项目 → 填原稿（例：`第一场 图书馆 日 内 / 林晚把剧本推到周野面前：这段冲突太软。`）
3. 点「准备」→ 界面显示三阶段：`normalize → storyboard → assemble`
   - 实测：**46 秒**（8.4s / 37.6s / 0ms）
   - `assemble` 是本地汇总，0ms —— 可以顺带解释"阶段化"的好处
4. **再点一次「准备」** → 立刻返回，`cached: true`
   - 实测：**0 秒**。讲点：切分指纹（源文本+镜数+用途 的 sha256）命中，省一次上游调用、且结果不漂移
5. 出图（`episode/frame`）→ 实测 **87 秒**（走备用网关），产出 3.9 MB JPEG

### 第三幕：字幕链路（约 1.5 分钟，本地能力，最稳）

1. 字幕页导入一个带字幕轨的 mp4
2. 「检测选区」→ 返回 `{x:9, y:83, w:82, h:11}`，6/6 帧命中（PyAV 取帧 + OpenCV 阈值）
3. 「拆轨」→ **秒级**完成，`已移除 1 条独立字幕轨；原片保留`
   - 讲点：这一步是**纯 Python MP4 box 解析**，不依赖 ffmpeg
4. 「转写」→ 本地 faster-whisper，实测 **43 秒**，输出分段 + SRT

### 第四幕：体量与诚实（约 1 分钟）

```
265 条旧路由 100% 注册        300 条注册路由实盘：0 个 5xx
322 项单测                    9 项门禁全 PASS（含 18 页点击、登录场景）
```

再主动说明 **5 条已知边界**（`spec/delivery.md` 第 7 节）：`update/*` 501、视频计费且慢、
图像主网关账号池可能空（已自动切备用）、像素修补仍需 ffmpeg、云端去字幕未配置。

## 3. 失败预案（上游不稳是常态，别慌）

| 现象 | 原因 | 现场应对 |
|---|---|---|
| 出图 502 `no available account` | KIE 账号池空 | 已自动切 `banana-pro`；若仍失败，改讲"字幕链路"（纯本地） |
| 分镜 502 `bad_model_output` | 渠道答成散文 | 已重问最多 3 次；仍失败就展示"失败阶段 + 前序结果保留"，讲容错设计 |
| 视频一直转圈 | 上游 1~3 分钟 | 只演示"提交 + 进度百分比"，**不现场等成片** |
| 某页 console 有 400 | 多为"故意错误卡登录" | 说明那是负向用例，不是缺陷 |
| 采集页打不开 | 目标站点不可达 | 换本地 `static/*.html` 演示解析能力 |

## 4. 三条红线

1. **演示不要中途换浏览器**：设备码派生自 UA，换浏览器等于换设备——需要重新登录（卡本身支持多设备，ctivations 是 PRIMARY KEY(device_code, card_hash)，实测同卡两台设备都能激活）。
2. **不要点 `update/*`**：本地重建版不做在线更新，返回 501（有意为之，不是坏了）。
3. **不要用 `-DataDir` 临时目录演示**：课题要求真实数据；临时目录里没有任何历史项目，看起来"空壳"。

## 6. 讲稿要点（一句话版本）

- **不是照抄接口**：265 条路由是行为等价重建，靠 `route-spec.json` + 真实响应样本对齐
- **失败要诚实**：缺模型返回 503 并指明该填哪个文件，不假装成功
- **省钱与稳定有机制**：切分指纹缓存（46s→0s）、JSON 重试、图像备用网关、分段生成规避上游断连
- **验证可复跑**：`tools/verify_all.py --with-ui` 一条命令给出 9 项 PASS/FAIL
